# 商业发布与许可证门禁

本项目把抖音创作者收益、广告分成、品牌合作、课程导流、客户委托和
账号商业化统一视为 `commercial`。

## CosyVoice3

默认使用 `FunAudioLLM/Fun-CosyVoice3-0.5B-2512`。2026-10-13 核验时，
官方 CosyVoice 代码仓库和 Hugging Face 模型页均标为 Apache-2.0。
模型许可允许商业工作流，但不自动授予参考声音的身份权、人格权或录音版权。

商用视频只能使用本人录制或已经取得明确商业授权的参考声音。不要使用官方示例录音、
来源不明的网络人声、影视片段、名人声音或未经许可的声音克隆。项目的 `voice.json`
必须记录参考文件和 `rights_confirmed: true`，许可证清单也必须写明权利来源。

## 商业 TTS

正式成片使用 `openai-compatible` 适配器或后续新增的供应商适配器。
“接口能调用”不等于“允许商业发布”。在 `license-manifest.json` 记录：

- 服务商和产品网址；
- 模型名称；
- voice ID 或声音名称；
- 订阅计划；
- 商业使用条款网址；
- 核对日期；
- 是否允许生成内容商用；
- 是否允许声音克隆；
- 若为克隆声音，声音权利人和授权证据。

条款不清楚时，状态写 `unverified`，预检脚本必须阻止最终归档。

## 其他素材

每个外部素材均需要一条记录：事实来源、图片、视频、音乐、音效、字体、
模型、声音和代码。推荐状态：

- `approved`：已经核对，允许当前商业用途；
- `original`：完全由本项目为当前视频创作；
- `public-domain`：已核对属于公有领域；
- `unverified`：尚未核对；
- `non-commercial`：明确禁止商业使用。

商业成片只允许前三种状态。事实本身通常不受版权保护，但文章表达、图表、
摄影、配乐和画面设计可能受保护。引用事实后重新组织表达和画面，不复制原作。

## 发布前清单

- `usage` 是 `commercial`；
- TTS 模型及当前套餐允许变现视频；
- 声音身份有权使用；
- BGM 和音效允许抖音商业发布；
- 所有视觉素材为原创、获许可或公有领域；
- 引文长度合理，并在片尾列来源；
- 没有上游参考片字幕、样片画面或未获许可的拆片内容；
- `scripts/preflight_release.py` 通过。

该清单用于防止明显误用，不构成法律意见。平台、模型和素材条款会变化，
应以发布当日的正式条款为准。
