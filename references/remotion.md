# Remotion 的使用边界

当前版本不依赖 Remotion。现有 Canvas 引擎已经提供确定性逐帧绘制、静帧检查、
分段渲染和 FFmpeg 混音；加入旁白只需要统一时间轴和新音轨。此时引入 React
时间轴会增加第二套渲染模型、依赖和迁移成本，不会直接改善讲解设计。

出现以下需求时，再把 Remotion 作为可选导出器或第二渲染后端：

- 同一内容需要批量输出 16:9、9:16 和 1:1；
- 需要给非程序员使用可视化时间轴；
- 需要大量复用 React 组件或网页数据组件；
- 需要服务器批量渲染或在线编辑器；
- 音轨、字幕轨和素材轨复杂到 FFmpeg 命令难以维护。

若以后接入，保留 `narration.json`、`timeline.json`、`license-manifest.json`
和成品编号规则，只替换画面组合层。不要同时维护两套事实表、旁白稿或时间轴。
